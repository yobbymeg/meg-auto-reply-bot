# 🤖 MEG AUTO-REPLY BOT

AI WhatsApp bot that replies to messages like YOU. Powered by Gemini AI.

## ✨ Features

- 🤖 **Gemini AI** — Human-like replies in English, Kiswahili, Sheng, and 50+ languages
- ✍️ **Typing indicators** — Shows "typing..." before replying (looks like you)
- 📱 **Baileys + Chrome** — Official WhatsApp Web library with Chrome browser fingerprint
- 🟢 **24/7 Online** — Always online with keepalive
- 🎫 **Pairing code** — No QR scanning needed
- 🌐 **Pairing site** — Premium UI with activate/deactivate button
- 💬 **.active command** — Toggle auto-reply ON/OFF from WhatsApp
- 📋 **.menu command** — Show bot menu in WhatsApp

## 🚀 Deploy on Render

1. Go to [render.com](https://render.com) → New Web Service
2. Connect: `https://github.com/yobbymeg/meg-auto-reply-bot`
3. render.yaml auto-detected → click **Create**
4. Wait ~2 min → live at `https://meg-auto-reply-bot.onrender.com`
5. Open the site → enter phone → get pairing code → link WhatsApp
6. Send `.active` in WhatsApp → bot starts replying!

## 📋 Commands (in WhatsApp)

| Command | Description |
|---|---|
| `.active` | Toggle auto-reply ON/OFF |
| `.menu` | Show bot menu |
